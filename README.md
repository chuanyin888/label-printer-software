# 设备标签打印软件

一个面向设备标签打印的 Windows 桌面小工具：扫码录入、自动识别型号/类型/SN/MAC、排版预览、批量打印，并支持自动更新。

运行环境：Windows 7 及以上（建议 Windows 10 以上），需要 .NET Framework 4.8。

## 版本

- **当前版本：v1.3.1**
- v1.3.1：修复“检查更新”报“无法连接更新服务器”。启用 TLS 1.2，并在配置的更新源无法访问时自动回退到 Gitee 默认更新源，国内网络也能正常检查更新。
- v1.3.0：界面改版。统一配色与卡片式布局（圆角分组、单一强调色、清晰按钮层级），表格与表单样式统一优化；保留全部原有功能与排版方式不变。

## 主要功能

- **两种录入方式**（左上角下拉框切换）
  - 二维码模式：扫码枪先扫设备二维码 → 自动识别出 型号/类型/SN → 再扫 MAC 条码。
  - 固定型号模式：手动填写 型号/类型（固定不变）→ 先扫 SN 条码 → 再扫 MAC 条码，适合型号固定的批量打印。
- **自动识别**：从二维码内容提取 型号、类型、SN；MAC 从第二条码读取，识别后每个字段都可手动修改。
- **标签设计**：包含 型号、类型、SN 条码＋文字、MAC 条码＋文字（Code128），支持上下堆叠布局、条码粗细自动适配。
- **预览与排版**：实时预览，鼠标可直接拖动文字/条码，选中后可改 字体大小、水平/垂直位置、条码高度；排版自动记住。
- **打印**：可勾选要打印的内容；可选择打印机，并能添加网络/局域网打印机；打印质量按打印机原生分辨率渲染（清晰、不缩放）。
- **自动保存**：每台设备自动写入 `数据\历史记录_日期.csv`（每天一个新文件），双击可重印，统计今日已打印数量；设置自动保存。
- **自动更新**：启动时自动检查新版本，也可点"检查更新"手动检查；发现新版提示下载、替换、重启，历史记录和设置不丢失。

## 使用方法

1. 双击 `设备标签打印.exe` 打开软件。
2. 首次使用：右侧选择打印机（如 TSC TTP-244 Pro），确认标签规格（默认 85×35mm）与打印精度（203 dpi）。
3. 选择录入方式，按提示扫描/填写，识别的设备会自动打印并保存（可在"扫描完成后自动打印并保存"复选框关闭）。
4. 历史记录在下方表格，双击可重印；右上角可"检查更新"。

## 构建与发布新版本

- 源码为单文件 `LabelPrinter.cs`，使用 .NET Framework 4.8 自带的 `csc.exe` 编译。
- 软件内置版本号：源码中的 `Updater.AppVersion`。
- 发布新版本步骤：
  1. 修改 `Updater.AppVersion` 为更大的版本号（如 1.4.0）。
  2. 重新编译得到新的 `设备标签打印.exe`。
  3. 上传到 Gitee 仓库的 `label-printer.exe`，并把 `latest.json` 里的 `version` 与 `download` 指向新版本。
  4. 如需走 GitHub 更新通道：在 GitHub 仓库的 Releases 页面新建发布，Tag 填 `v1.4.0`，把新的 exe 作为附件上传。
  5. 发布后，已安装的软件会自动检测到并升级。
- 更新接口：默认读取 Gitee 仓库的 `latest.json`；也可配置为 GitHub Releases（`releases/latest`）。仓库公开时无需令牌；若为私有仓库，需配置带只读权限的 Fine-grained Token。

## 数据

软件目录下会生成 `数据` 文件夹：`历史记录_日期.csv`（按天保存的设备记录，可用 Excel 打开）和 `设置.ini`（打印机、标签规格、排版等设置）。
