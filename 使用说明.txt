设备标签打印软件 使用说明
==============================
版本：v2.3.1

【本版更新（v2.3.0 → v2.3.1）——重要修复】
0. 修复“点检查更新、提示更新完成，但版本一直升不上去”：老写法只等 1 秒就复制文件，
   慢一点或被占用时会悄悄失败。现在改成：等程序真正退出 → 最多重试 30 次替换 → 校验文件大小 → 重启，
   全过程写进程序同目录的「更新日志.txt」；万一失败会弹窗提示手动覆盖的办法。
   如果那台电脑的老版本更新总是装不上：把《一体化工具.exe》同目录放一个「一键更新.bat」，双击即可强制升级。
1.（v2.3.0 的内容）设备标签打印新增「扫码删除」、扫码装箱新增「增加/替换」、设置里新增「查找」。

【v2.3.0 带来的变化】
1. 设备标签打印（历史记录）新增「扫码删除」：点开后扫一个 SN/MAC 就删掉历史里对应的那一条，
   下面的「已删除」清单和「核对区」会同步记录，扫完可以整体核对。
2. 扫码装箱新增「增加…」「替换…」：可以挑一箱历史箱来改 ——
   左边填新的 SN/MAC（每行一条，只填 SN 或 MAC 其中之一，另一项自动匹配），右边填被替换掉的 SN/MAC；
   按钮有「增加 / 替换 / 替换+新增 / 只检查不执行」；
   · 被替换的编号如果同时出现在两个箱子里，会提示“被替换数据在两个箱子里面，无法进行操作”；
   · 「替换」要求左右数量一致；两边必须同为 SN 或同为 MAC；数量不一样用「替换+新增」。
   改完点「打印标签」保存成新箱，老箱文件会自动改名标注“此箱已修改请查看<新箱名>”。
3. 设置菜单新增「查找（SN/MAC）…」：输入 SN 或 MAC（可只输后几位），会显示它在标签打印历史里的
   录入/打印时间，以及装进了哪一箱、那一箱的打印时间。

【v2.2.1 带来的变化】
1. 扫码装箱新增“数据对比”：打印时如果发现这一箱数据和今天已存的某一箱一模一样
   （重复打印、没墨重打都算），新文件名字后面自动加 -原批次时间，例如：
     正常：20260916_0904.xlsx
     重打：20260916_0931-0904.xlsx（表示和 09:04 那箱是同一批数据）
     再重打：20260916_0931-0904-2.xlsx
   同一分钟但数据不同 → 20260916_093104.xlsx（带秒），不会和重打混淆；
   打印后状态栏会提示“数据和 xxx 相同（重复打印）→ 已另存为 …”。

【v2.2.0 带来的主要变化】
1. 辅助安装：软件启动会自动检查运行环境 —— 没装 Python 就静默安装，缺插件自动补装；
   设置菜单新增「辅助安装…」，里面有「安装 / 修复 Python」和「检测缺少插件并自动安装」两个按钮，
   过程都显示在「扫码伴侣日志」里（不用再手动敲 pip 命令）。
2. 更新有进度条了：下载更新时显示“已下载 x/y MB（n%）”。
3. 扫码装箱：多型号改成一排三个；右侧加整条滚动条（型号多、窗口小都不会把扫码区顶出屏幕）。
4. 装箱标签：型号多时自动缩小字体不越界；所有条码统一宽度（SN 和 MAC 完全一致）；
   条码和它自己的文字紧贴、和下一个条码留空隙；打印预览里可调「条码-文字间距」「条码-行间距」
   （自动记住）；下半部分标题去掉，条码排得更舒展。

【v2.1.0 带来的主要变化】
1. 单文件版：扫码伴侣（光猫高拍仪识别）已内置进 exe —— 别的电脑点一次
   「设置 → 检查更新」就能连它一起升级，不用再手动复制 py 文件和 zxingcpp 目录。
2. 识别升级：先“找正方形”定位二维码、再按原分辨率局部解码，高密度二维码用 ZXing 兜底
   → 以前读不出型号的机型（如 ZTE ZXHN F677V2）现在型号/类型/SN/MAC 全自动识别。
3. 录入提速：识别到的内容整段一次性发送进录入框，每台从 0.7~3.1 秒降到 0.02~0.3 秒，
   而且不会再被中文输入法敲成乱码。
4. 空台面过滤：高拍仪下面没放设备时不会白跑一遍。
5. 清晰度提醒：画面发糊时日志直接提示“对焦/设备高度问题”（正常清晰度应在 300 以上）。
6. 残留进程保护：启动前自动结束上次没退干净、占着摄像头的旧扫码伴侣。

【高拍仪自动识别（扫码伴侣）怎么用】
· 打开《一体化工具》时它会自动启动，点左侧「开始识别」即可；
· 把设备背标朝上放到高拍仪下面，画面一稳就自动识别并把 型号/类型/SN/MAC 填进软件；
· 一台录完听到“滴”一声就拿走换下一台，不用点任何按钮；
· 日志里若出现“画面偏糊（清晰度 < 300）”，说明设备高度或对焦变了：
  把设备垫到原来的高度，或在工具里点一次「一键找焦点」。

一、功能简介
1. 扫码枪扫两次即可完成一台设备的录入：
   第 1 次扫设备二维码（自动识别出 型号、类型、SN）
   第 2 次扫 MAC 条码（自动识别 MAC 地址）
   识别完成后自动打印标签并保存记录，无需手动点击。
2. 标签上包含：型号、类型、SN 条码＋SN 文字、MAC 条码＋MAC 文字。
3. 可选择打印哪些内容（右侧"打印内容"勾选框）。
4. 可选择打印机（右侧"打印机"下拉框）。
5. 自带预览功能：用鼠标在预览图上直接拖动文字/条码调整位置，
   选中后可在右侧修改字体大小、位置、条码高度等。
6. 所有记录自动保存，关闭软件再打开会自动恢复上次的记录和设置。

二、使用方法
0. 选择录入方式（左上角下拉框）：
   - 二维码模式：扫码枪先扫设备二维码（自动填 型号/类型/SN），再扫 MAC；
   - 固定型号模式：手动填好 型号/类型（固定不变），然后扫码枪
     先扫 SN 条码，再扫 MAC 条码，适用于型号固定的批量打印。
1. 双击"设备标签打印.exe"打开软件。
2. 第一次使用：
   - 在右侧选择你的打印机（如 TSC TTP-244 Pro）；
   - 确认标签纸规格（默认 85×35mm，若换纸请修改宽和高）；
   - 确认打印精度（TSC TTP-244 Pro 为 203 dpi）。
3. 开始干活：
   - 光标停在"扫码输入框"；
   - 用扫码枪扫设备二维码 → 自动识别出型号/类型/SN；
   - 再扫 MAC 条码 → 自动打印并保存，等待下一台。
4. 若取消勾选"扫描完成后自动打印并保存"，扫描完可手动点
   "打印当前设备"或"仅保存"。
5. 历史记录在下方表格中，双击任意一条可重新打印；
   也可以选中后点"重印选中"、"删除选中"、"清空全部"。
6. 只想看某一天的记录：点历史记录区右侧的"日期"框，会弹出一个日历——
   - 日历上"浅灰色底"的日期表示那天有记录，一眼就能看出哪几天有数据；
   - 鼠标停在某个日期上，会提示"当天 N 条记录"；
   - 点某一天，下面的表格就只显示那一天的记录；
   - 左/右小箭头翻月，点左下角"今天"直接回到今天；
   - 打开软件时默认显示"最近有记录的那一天"。

三、添加网络打印机
1. 点右侧"添加网络打印机…"，会打开 Windows 的添加打印机窗口，
   按提示找到局域网里的打印机并完成添加；
2. 如果知道打印机的网络地址（形如 \\192.168.1.100\打印机名），
   也可以直接填在下面的输入框里，点"连接"；
3. 添加完成后点"刷新"，就能在下拉框里选到它。

四、标签排版调整
1. 预览图上的每个文字/条码都可以直接用鼠标拖动。
2. 点中某个元素后，右侧"排版属性"可修改：
   - 字体大小（文字）
   - 水平/垂直位置
   - 条码高度（条码）
   - 是否在标签上显示
3. 想恢复初始排版，点"恢复默认排版"。
4. 排版调整会自动记住，下次打开还是你调好的样子。
5. 提示：当 SN/MAC 还没扫、或打印完清空后，预览里会显示占位假条码，
   方便你随时拖动调整条码位置；真正打印时用的是扫描到的真实条码，不会打到假码。

五、数据保存位置
软件旁边会生成"数据"文件夹：
- 历史记录_日期.csv —— 每天一个文件（如 历史记录_2026-09-12.csv），可用 Excel 打开
- 设置.ini —— 软件设置（打印机、标签尺寸、排版等）
也可以点历史记录区右侧的"打开数据文件夹"直接查看。

六、常见问题
Q: 扫码枪扫了没反应？
A: 确认扫码输入框有光标；确认扫码枪是"键盘模式"（扫完自动输入）；
   不要开着中文输入法。

Q: MAC 扫了提示格式不正确？
A: MAC 条码应为 12 位字母数字（如 4413D003B768）。

Q: 打印失败？
A: 检查打印机是否开机、是否缺纸；
   检查 Windows 打印机设置里 TSC 驱动是否已设为你现在的标签纸尺寸；
   若刚换过标签纸，先改软件的"标签规格"，再确认驱动里的纸张大小一致。

Q: 网络打印机连接不上？
A: 确认打印机已开机且和电脑在同一个局域网；
   用添加窗口里的"按 IP 地址添加打印机"方式试试；
   或者把 \\IP地址\共享名 填进输入框后点"连接"。

Q: 软件打不开或报错？
A: 如果提示错误，软件旁边会生成"错误日志.txt"，把里面的内容发给我即可定位问题；
   如果是设置损坏导致的，可以先删除"数据\设置.ini"再打开（历史记录不会丢）。

Q: 打印出来模糊或条码扫不上？
A: 1) 右侧打印机一定要选 TSC TTP-244 Pro，不要选"Microsoft XPS Document
   Writer"（它是虚拟打印机，不会出纸）；
   2) 到 Windows"打印机设置"里把 TSC 驱动的纸张尺寸设为 85×35mm；
   3) 新版已把 SN/MAC 条码加粗（上下堆叠、横向拉宽），打印更清晰；
      如果还是嫌细，可在预览里选中条码、调大"条码高度/mm"。

九、软件更新
本软件支持自动更新。
1. 打开软件后会自动检查是否有新版本（每台设备都检查一次）；
2. 也可以点菜单栏「设置 → 检查更新…」手动检查；
3. 若提示需要更新地址，按提示粘贴仓库地址或更新接口地址，
   如有访问令牌（Token）也一并粘贴；
4. 发现新版本会提示，点"是"即自动下载、替换并重启软件，数据（历史记录、设置）不会丢失。

Q: 第一次运行提示"Windows 已保护你的电脑"？
A: 这是对未签名程序的正常提示，点"更多信息"→"仍要运行"即可。

七、更换标签纸
在右侧"标签规格"里改宽/高（单位 mm），预览会立即变化。
同时建议到 Windows 的"打印机设置"里把 TSC 驱动的纸张尺寸改成同样大小，
这样打印位置最准确。

八、字段说明
型号/类型/SN 来自二维码内容：
型号 ← type 参数（如 ZXHN F677V2）
类型 ← model 参数（如 GPON）
SN ← sn 参数
MAC ← 第二次扫描的 12 位条码
识别后每个字段都可以手动修改再打印。

十、屏幕分辨率
软件会按当前电脑的可用屏幕区域（已扣掉任务栏）自动决定窗口大小，
小屏笔记本（1366×768 等）打开也不会被任务栏挡住或裁掉底部。
- 窗口调小后，左右两栏会自动出现滚动条，内容不会被裁掉；
- 历史记录区（含右侧按钮、底部统计行）始终完整显示；
- 把窗口拖到更小的显示器、改分辨率或改缩放比例，软件会自动收回屏幕内。

十一、NAS 备份怎么同步（重要，v2.0.9 起）
同步规则：以"每一条设备记录"为单位合并，本机和 NAS 互相补齐，只增不删。
1. 本机有、NAS 没有的记录 → 自动上传到 NAS（按机器名分文件夹）。
2. NAS 有、本机没有的记录 → 自动补回本机（本机历史丢了也能自动恢复）。
3. 本机历史文件损坏/读不出来 → 不会去覆盖它，而是用 NAS 的记录把它补回来。
4. 删除单条记录 → 会记入 数据\删除记录.txt，这条以后不会再被 NAS 合并回来。
5. 点"清空全部"会多问一句：
   - 选"是"：本机和 NAS 上本机那份一起清空（彻底删除）；
   - 选"否"：只清空本机，NAS 备份保留（下次同步会把记录合并回来）。
6. 从 NAS 补回来的记录，界面上的列表会自动刷新，不用重开软件。
同步状态会写在 NAS 设置窗口里，例如"从 NAS 补回 12 条，上传 3 条"。
